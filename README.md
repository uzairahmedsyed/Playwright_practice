# Playwright Automation Practice

This is my initial repository where I am learning **Python** and **Playwright**. I am using this space to practice basic automation testing concepts and develop my first automation scripts.

## Project Overview
The goal of this project is to master web automation techniques, such as:
* **Browser Management:** Launching and managing Chromium, Firefox, and Webkit.
* **Locators:** Identifying web elements effectively.
* **User Actions:** Automating interactions like `Click`, `Type`, and `Hover`.
* **Validation:** Checking test results and generating reports.

## Prerequisites
To run these scripts, ensure you have Python and Playwright installed on your system:

1. **Install Playwright:**
   pip install playwright

2. **Install Browsers:**
   playwright install

## How to Run
To execute the practice script, run the following command in your terminal:

python first_test.py
